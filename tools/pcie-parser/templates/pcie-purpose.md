# Project Purpose - PCIe Base Specification

## Goal

Build a source-grounded knowledge base for answering engineering questions about
the PCI Express Base Specification.

## Key Questions

1. What does each PCIe mechanism require, permit, and forbid?
2. Which packets, fields, registers, timers, and state machines interact?
3. How do requirements differ between available spec versions?

## Scope

In scope:
- PCIe Base Specification sections and objects parsed from canonical PDFs.
- Protocol mechanisms, state machines, packet formats, registers, fields, and timing rules.
- Version-aware comparison when source material supports it.

Out of scope:
- Guessing behavior not supported by the spec text.
- Treating LLM-generated summaries as raw source.
- Replacing source citations with unsupported paraphrases.
